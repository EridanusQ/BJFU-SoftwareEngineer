# L4_Code_ReservationCore.puml

本图是预约核心代码层视图，用于把 L3 中的组件进一步落到关键领域对象。重点对象包括 Reservation、TableSlot、CapacityLock、Deposit、ReservationPolicy 和 DomainEvent，它们共同维护“同一门店、同一桌位、同一时间段不能重复确认”的核心不变式。

代码层视图强调领域规则应放在领域对象和策略对象中，而不是散落在页面、控制器或数据库触发器里。这样做可以让容量锁、改期规则、取消规则、押金状态和爽约处理在测试用例中被独立验证。

本图主要服务于后续实现与测试设计。实现阶段应围绕 Reservation 聚合编写单元测试，覆盖正常创建、重复提交、容量冲突、支付失败、取消退款和到店核销等路径，并与 D2-5 的接口响应保持一致。
