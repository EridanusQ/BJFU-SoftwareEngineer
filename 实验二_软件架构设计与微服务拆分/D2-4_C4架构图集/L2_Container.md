# L2_Container.puml

本图是 C4 Level 2 容器图，用于说明平台内部的主要运行单元及其依赖关系。当前架构将系统划分为 Web 前端、预约服务、会员服务、支付适配器、通知服务、运营后台、预约数据库、会员数据库以及日志与监控能力。

容器划分遵循 D2-2 的限界上下文：预约服务承载预约创建、改期、取消、签到核销等核心流程；会员服务维护会员资料、积分、优惠券和隐私授权；支付适配器隔离第三方支付差异；通知服务承接短信、站内信和邮件等异步通知。

该图也是 D2-3 最终选择“微服务 + 事件驱动 + CQRS”的架构证据。同步调用用于必须立即得到结果的查询或命令，异步消息用于通知、运营分析和推荐更新，数据库按上下文拆分以降低共享表带来的耦合。
