## 查看方式

克隆仓库后，可以通过下面命令切换到对应实验分支：

```bash
git switch experiment-1
git switch experiment-2
git switch experiment-3
git switch experiment-4
```

也可以在 GitHub 页面左上角的分支选择器中选择对应分支查看文件。
