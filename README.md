# BJFU-SoftwareEngineer

北京林业大学《软件工程》课程实验仓库。

本仓库采用“一个实验一个分支”的方式组织产出物。`main` 分支只作为导航说明页，具体实验文档、代码、图表和运行报告请切换到对应实验分支查看。

## 分支说明

| 分支 | 对应实验 | 主要内容 |
| --- | --- | --- |
| `experiment-1` | 实验一：需求工程 | 需求获取计划、SRS、UML 模型、需求追踪矩阵、需求验证记录等 |
| `experiment-2` | 实验二：架构设计 | C4 架构图集、ADR 架构决策记录、上下文映射、ER 图、架构评审材料等 |
| `experiment-3` | 实验三：DevOps 流水线与容器化部署 | DevOps 设计方案、源代码与配置仓库、CI/CD 配置、Docker/K8s/Helm、可观测性配置等 |
| `experiment-4` | 实验四：软件质量工程与 AI 辅助代码审查 | 测试计划、测试用例、自动化测试代码与报告、非功能测试报告、AI 代码审查分析、缺陷台账等 |

## 查看方式

克隆仓库后，可以通过下面命令切换到对应实验分支：

```bash
git switch experiment-1
git switch experiment-2
git switch experiment-3
git switch experiment-4
```

也可以在 GitHub 页面左上角的分支选择器中选择对应分支查看文件。
